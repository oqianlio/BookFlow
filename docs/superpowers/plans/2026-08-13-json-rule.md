# 书源 JSON 规则提取（@Json: / $.）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 支持书源规则从 JSON 响应提取数据（`@Json:` 前缀与 `$.` 路径），兼容 legado，使番茄聚合等 JSON-API 书源的探索/搜索/目录可用。

**Architecture:** `parseRule` 识别 `@Json:` 与 `$.`/`$[` 开头 → `{type:"json"}`；新增纯函数 `jsonGet(obj, path)` 做嵌套路径取值；`extractList`/`extractSingle` 加 json 分支（从 `ctx.result` 解析 JSON）；新增 `extractFromJsonObject` 处理字段级取值（含 `@js:` 组合与 URL 解析）。

**Tech Stack:** TypeScript + vitest（jsdom）。无新依赖。

## Global Constraints

- 仅支持简单路径：`$.a.b`、`$[0]`、`$.a[0].b`。不支持 `@Json:[*]` 通配。
- 不实现 `isJSON` 自动嗅探——仅当规则显式以 `@Json:` 或 `$.`/`$[` 开头时走 JSON 分支。
- JSON 解析失败 → 返回 `[]`（列表）/ `""`（单值），不抛错。
- 路径不存在 → `undefined` → 空结果。
- 现有测试保持绿：`npm test`（当前 192），`npm run build`（tsc + vite）通过。
- Shell 为 PowerShell 7；测试命令 `npx vitest run <file>`；不修改 `docs/` 与 `.git/`。

```ts
export function jsonGet(obj: any, path: string): any {
  if (obj == null) return undefined;
  let cur: any = obj;
  let p = path.trim();
  if (p.startsWith("$.")) p = p.slice(2);
  else if (p.startsWith("$")) p = p.slice(1);
  if (!p) return cur;
  const tokens = p.match(/[^.[\]]+|\d+(?=\])/g) ?? [];
  for (const tok of tokens) {
    if (cur == null) return undefined;
    cur = cur[tok];
  }
  return cur;
}
```

```ts
export function extractFromJsonObject(
  obj: any,
  rule: string,
  ctx?: { baseUrl?: string; sourceKey?: string },
): string {
  if (obj == null || typeof obj !== "object") return "";
  const s = rule.trim();
  if (!s) return "";
  const jsIdx = s.indexOf("@js:");
  const pathPart = (jsIdx > 0 ? s.slice(0, jsIdx) : s).trim();
  const path = pathPart.startsWith("@Json:")
    ? pathPart.slice(7).trim()
    : pathPart.replace(/^\$\.?/, "");
  const v = jsonGet(obj, path);
  if (jsIdx > 0) {
    return String(evalJs(s.slice(jsIdx + 4), { doc: emptyDoc(), result: v, baseUrl: ctx?.baseUrl, sourceKey: ctx?.sourceKey }) ?? "");
  }
  if (v == null) return "";
  const str = String(v);
  const isUrlField = path.endsWith("bookUrl") || path.endsWith("coverUrl") || path.endsWith("thumb_url");
  if (isUrlField && ctx?.baseUrl && !/^[a-z][a-z0-9+.-]*:/i.test(str)) return resolveUrl(str, ctx.baseUrl);
  return str;
}
```

同时把 `extractFromJsObject`（line 263-285）内部委托给 jsonGet 以支持嵌套路径（保持现有 `@js:` 行为不变）：

```ts
export function extractFromJsObject(obj: any, rule: string, baseUrl?: string, sourceKey?: string): string {
  return extractFromJsonObject(obj, rule, { baseUrl, sourceKey });
}
```
