@keyframes page-in {
  from { opacity: 0; transform: translateY(8px); }
  to { opacity: 1; transform: translateY(0); }

@keyframes spin {
  to { transform: rotate(360deg); }
}
@keyframes dialog-in {
  from { opacity: 0; transform: scale(0.96); }
  to { opacity: 1; transform: scale(1); }
}

.spinner {
  display: inline-block;
  width: 28px;
  height: 28px;
  border: 3px solid var(--outline-variant);

- [ ] **Step 1: App.tsx 主区页面组件加 key**

给主区 5 个页面组件加 `key`（用 area 名），触发 `.app-main > *` 动画：

```tsx
<main className="app-main">
  {state.area === "home" && <HomePage key="home" ... />}
  {state.area === "bookshelf" && <LibraryPage key="bookshelf" ... />}
  {state.area === "discover" && <DiscoverPage key="discover" ... />}
  {state.area === "rss" && <RssPage key="rss" />}
  {state.area === "my" && <SettingsPage key="my" ... />}
</main>
```

（key 变化 → React 卸载旧组件挂新组件 → 动画重新触发。）

- [ ] **Step 2: ExplorePage 加载态换 spinner**

`src/pages/ExplorePage.tsx` line 81：

```tsx
{busy ? (
  <span className="loading-state"><span className="spinner" /><span>加载中…</span></span>
) : books.length === 0 ? (
  ...
)}
```

注意：`discover-results` 是 flex column，`.loading-state` 内联 flex 会居中；若需居中可在 `busy` 分支外包 `<div className="panel-empty">`。以视觉为准调整：

```tsx
{busy ? (
  <p className="panel-empty"><span className="loading-state"><span className="spinner" /><span>加载中…</span></span></p>
) : books.length === 0 ? (
  ...
)}
```
