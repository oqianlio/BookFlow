# 阅读体验 R24：换源保持同一本书

> **Status:** Implemented  
> **Date:** 2026-08-15  
> **Scope:** 修复「切换书源后显示的不是同一本书」。

## 背景

用户反馈：阅读中（或详情页）点「换源」，选一个其他书源的结果后，显示的「不是同一本书」。

## 根因

1. **换源搜索缺作者**：`ReaderPage` 的换源面板 `SwitchSourcePanel` 传 `author=""`（硬编码），搜索词只有书名。常见书名（如《重生》《赘婿》《斗破苍穹》）在其他源有大量同名书，结果混杂不同作者/不同内容的书，用户选中后自然「不是同一本书」。
   - `SourceBookPage`（详情页）换源已传 `info.author`，只有阅读页漏传。
2. **换源后书名不统一**：换源跳转到新源详情页时用搜索结果 `hit.title`（源规则可能对书名做处理，如加「（全文）」「第X部」后缀），与用户正在读的原书书名不一致，观感上像换成了另一本书。

## 方案

1. **阅读页携带作者搜索**：`ReaderPage` 加载目录时从 `fetchToc` 返回的 `info.author` 记录作者，换源面板 `author={author}` 传给搜索 → 按「书名 + 作者」搜索，精确匹配同一本书。
2. **换源后保持原书书名**：`App.tsx` 中阅读页的 `onSwitchSource` 跳转详情页时，用 `state.bookTitle`（用户正在读的书名）覆盖搜索结果的 `title` → 新源详情页始终显示同一书名，作者/简介/封面为新源解析的真实信息。

## 不改动

- 换源后的流程仍是「新源详情页确认 → 开始阅读」（与详情页换源一致）。
- 不同源同名同作者但内容版本不同（源数据本身的问题）不在本次范围。

## 测试

- `ReaderPage.source.test.tsx`：换源面板收到 `author`（mock 面板捕获 props，目录 HTML 解析出作者）。
